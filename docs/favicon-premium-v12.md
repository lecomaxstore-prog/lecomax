# Shopping bag favicon

Created using built-in imagegen with the user-provided black-and-green bag icon as the visual reference. Applied locally to the website metadata, PWA manifest, default favicon, and Expo app configuration.

Native assets: `mobile/assets/images/app-icon-shopping-v12.png` (opaque 1024px), `app-icon-shopping-adaptive-v12.png` (padded Android icon), and `favicon-shopping-v12.png` (Expo web). The splash uses the new icon on black. Native launcher and splash changes require a new app build; they are not delivered by a JavaScript-only update.

Source: `public/brand/favicon-premium-v12-source.png`
Favicon: `public/brand/favicon-premium-v12.ico` (16, 32, 48 pixels)
Export script: `node scripts/generate-premium-favicon-v12.mjs`

## Prompt

Create a finished premium favicon/app icon for L’ecomax closely matching the user's attached reference image. Reference role: primary visual design reference. Preserve the core design: black softly rounded square tile, a bold white L forming the left side and base of a shopping bag, vivid green right side forming a stylized M/fold, a green arch shopping-bag handle above, and one elegant green leaf integrated diagonally through the center. Maintain the same recognizable composition, green-to-lime highlights, white satin finish, and restrained dimensional polish. Refine geometry and symmetry, smooth precise edges, balanced proportions, clean negative spaces. Make the handle and leaf opening sufficiently thick and clear for small favicon sizes. Enlarge the central emblem to occupy about 76 percent of the canvas; minimal outside margins. Strong pure-black background, luminous brand green #3ecf4c with tasteful lime highlights, bright white L. Premium ecommerce identity, polished but not excessively glowy; no added text, no letters outside the symbol, no tagline, no mockup, no decorative scenery. One square finished image only. Match this supplied reference rather than the previous standalone letter designs.
