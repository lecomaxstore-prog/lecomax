# Bundled Arabic typography

The app uses Noto Sans Arabic Regular and SemiBold from the official Noto font archive:
https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSansArabic

These static TTF files are bundled by Expo for offline use on web and native.
Their SIL Open Font License is included in `Noto-OFL.txt`.
Web font stacks include sans-serif fallbacks if loading fails.

The earlier IBM Plex assets and their `OFL.txt` are retained for existing references.
