# Earth surface texture

`earth-2048.jpg`: NASA Blue Marble land/ocean/ice composite, 2048 × 1024 pixels.
Downloaded 2026-10-16 from https://eoimages.gsfc.nasa.gov/images/imagerecords/57000/57730/land_ocean_ice_2048.jpg

Credit: NASA Earth Observatory / Blue Marble. Historical composite, not live imagery. NASA imagery use guidance: https://www.nasa.gov/nasa-brand-center/images-and-media/
No NASA logo or endorsement is implied. Natural Earth boundaries remain public domain and are a separate generalized layer.

Cloud wisps and planetary color patterns are generated original illustrative textures. Atmospheric glow is an artistic limb effect, not a quantitative scattering model. The Earth texture is decoded only when an exploration frame mounts; all assets are bundled for offline scene use after authentication.
