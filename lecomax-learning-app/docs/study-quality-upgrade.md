# Study quality update

The shared lesson screen now includes guided reading, a saved recall response, comparison against lesson summaries, self-assessment, and an exercise plan. Self-assessment never marks a lesson complete or claims to grade free text. “Not yet” and “With help” add the lesson to the existing review collection. Drafts use reserved study: keys and remain compatible with version 1 progress storage.

Four new lessons in Arabic, French and English cover understanding examples, retrieval with feedback, problem solving, and study planning. They are available from More, lesson study guidance, and search. Four introductory Python lessons (variables, conditions, loops, functions) also have authored worked explanations, misconceptions, transfer exercises, and quizzes. Existing migrated content is preserved; enrichments are applied by services/lesson-enhancements.ts. This is not a complete rewrite of every lesson.

Study guidance draws on retrieval practice and spaced practice explanations from The Learning Scientists:
- https://www.learningscientists.org/learning-scientists-podcast/2018/3/7/episode-14-how-students-can-use-spacing-and-retrieval-practice
- https://www.learningscientists.org/learning-scientists-podcast/2018/3/21/episode-15-how-students-can-use-interleaving-elaboration-dual-coding-and-concrete-examples

Session timing and review intervals are adjustable examples, not promises of faster learning or automatic reminder schedules.

The installed Android application must be rebuilt and updated to include these bundled screens and offline lessons.
